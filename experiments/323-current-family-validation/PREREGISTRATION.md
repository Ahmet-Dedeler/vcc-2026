Coordinator: Codex, main agent only. No subagents, submission, cloud rental,

## Decision

Can the already-used H1 reference support a held-context-safe, all-six-member
regression panel for the current norm-weighting family? This is retrospective
validator qualification. Board outcomes are already known; calling this a new
confirmation or an unbiased board prediction would be incorrect.

The independent recipient is one H1 hESC context, not 85 independent contexts.
Target bootstraps quantify uncertainty within this reference, not generalization
to another line. No outcome-dependent target filtering or parameter tuning.

## Eligibility and novelty

Use the metadata inventories and recorded reliability results of 267/273/278/285
to document the eligible contrasts, without repeating their raw-cell searches.
H1 has 85 targets at 400 cells, matching the challenge cell budget and chemistry
but not its cancer-cell population, target set, or effect-strength distribution.
Orion supports relative direction checks but has depth/batch issues; K562 has
sparse DE on the panel; Broad-16 and Nadig do not cover the challenge targets.
CD4 raw-cell extraction is not part of this experiment.

This extends 273 with current norm-weighting composition, a panel-specific
operator, actual emitted counts, and all six metrics. It does not relabel
317/318's historical rc_callset baseline as the current model.

Code inspection before freeze found that 170/273 supply the A/B/C operator
columns when whitening H1. The operator's coordinate labels are internally
consistent, but its exclusion set is wrong for H1. Quantify the overlap and
the corresponding input-to-scored-coordinate contribution before reading any
new model comparison. Do not call this held-H1-truth leakage: its fitting data
are other lines. It is leakage of excluded target coordinates through a dense
transform, and a mismatch with the production panel contract.

## Gates and measurements

1. Synthetic tests: same-axis accepted, wrong exclusion set rejected, reordering
   detected, correct symbol mapping, and a target-coordinate-only input cannot
   affect any scored coordinate through the new operator.
2. Rebuild historical unset H1 pre-whitening rows from the production donor
   preparation; max absolute difference from 170's `cand_h1` <= 1e-10.
   Rebuild cap15's A/B/C pre-whitening and PM-corrected hashes and require exact
   equality to 319's build metadata. This is a construction test, not scoring.
3. New operator has no H1 target columns, contains only named training donors,
   and passes production's axis/hash loader. The old operator must fail this
   loader on H1. Do not disable the loader's guard.
4. CD4 complete coverage must match 273's 77/85, excluded coordinates remain
   zero in its residual, and H1 union remains absent.
5. Evaluate **actual emitted integer counts** with cell-eval2's vcc2026
   definitions, serially. Reproduce at least one historical six-member row
   through any faster scoring implementation before trusting it; otherwise use
   the installed full scorer. Report raw members and explicitly labelled
   anchor-scaled local values; never treat H1 anchors as A/B/C anchors.
6. Record per-target PDS and DE, panel-level MSE, paired target bootstrap
   intervals (10,000 draws, seed 20260909) where defined, and reference DE-count
   distribution. Do not invent per-target MSE.

Known board contrasts: plain15 - uniform positive; cap15 - plain15 positive;
plain30 - plain15 negative; parity15 - plain15 negative in overall. Compare
their individual member signs as well. These are known answers to be
retrodicted, not labels to fit. No universal local-to-board transfer factor.

Qualification requires all engineering gates, cap15 PDS greater than the
shuffled negative control with a positive paired-bootstrap lower bound, and
correct overall signs on all four historical contrasts. If intervals straddle
zero, mark the contrast unresolved even if its point sign agrees. Failure
disqualifies this surface as a stand-alone selector for this arm family;
it does not show the production arm is wrong or all response models impossible.

new reserve reads, or spending cloud/assay money. A successfully qualified
