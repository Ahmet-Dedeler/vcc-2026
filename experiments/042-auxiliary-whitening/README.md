The production effect estimate uses K562-gwps, Orion-HCT116, and
Orion-HEK293T. A perturbation screen does not need to overlap the 300 challenge
targets to help estimate the global response covariance used by whitening.

to the whitening basis. Predictions remain unchanged before the operator.
