## 3. H-622 — "new model families": what I recommend NOT doing, and why

- **Deep cross-line models / foundation embeddings / GPU training:** the supervised signal a learned model would need
  (a line's deviation from the shared response) is not predictable from what we observe of a new line (289, 358, 359,
  441, 491). Public data offers ≤ ~15 lines with matched targets. STATE scores pds 0.50 on this board. Without a new
  signal, a bigger model fits noise. **Revisit if Pisces or another multi-line genome-scale CRISPRi release lands.**
- **Learned per-target bulk magnitude** (518's oracle pot is +0.018 … +0.023; ~20 % of X remains after key + cap): the
  only feature I can add that is new is paralog expression in the recipient (buffering). I price it low (≤ +0.002) and
  would test it only on Broad-16's 12 working lines + the Orion/K562 pairs as an evening filler.

## 4. Notes for Phase 2 (critique of [d4cd5f]'s §3 "programme" prize)

- The LOTO oracle (0.554 fid-like) is computed against the reference's own control group. Each gene's realised lfc sign
  shares that control mean's sampling noise across all 300 targets. That shared-control component is real for the
  scorer, but **no external source can know it**. 491's halves check shows the effect: the own-control programme read
  +0.0055 with all controls and only +0.0024 with control halves. So the reachable programme prize is below the "+0.017
  at oracle" headline, and probably well below half of it.
- The one control-side term that IS knowable is construct composition. The control pool is 46 NTCs × 400 cells, and we
  have the `ntc_id` of every cell. Any NTC-specific effect (F16-type seed repression) shifts the pooled control mean, and
  therefore every target's lfc sign, the same way. A robust per-gene NTC-composition offset (pooled mean vs median of the
  46 construct means) is computable for D/E/F on the day. I expect it to touch few block genes (≤ +0.001); listed so
  nobody re-derives it.
